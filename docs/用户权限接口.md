# 用户权限接口

## 接口说明

本文档描述任务相关获取用户信息的API接口。

## API_BASE_URL

192.168.1.42:8084

---

## 获取用户是否有创建任务权限

### 接口信息

- **接口路径**: `/web/ai/ai-diagnosis/hasCreateTaskPermission`
- **请求方法**: `GET`
- **接口描述**: 获取用户是否有创创建任务权限

### 请求参数

| 参数名    | 类型   | 必填  | 说明   |
| ------ | ---- | --- | ---- |
| userId | Long | 是   | 用户id |

### 响应参数

| 参数名  | 类型      | 说明          |
| ---- | ------- | ----------- |
| code | Integer | 状态码，200表示成功 |
| msg  | String  | 提示信息        |
| data | Long    | 数据信息        |

### data对象

| 参数名           | 类型     | 说明                       |
| ------------- | ------ | ------------------------ |
| hasPermission | String | 是否拥有任务权限 false 没有 true 有 |

### 响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "hasPermission": "true"
  }
}
```
