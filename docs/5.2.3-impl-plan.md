# 5.2.3 各异常指标对应推送动作 — 实现方案

## 1. 目标

将「5.2.3 各异常指标对应的具体推送动作」表在系统中实现：诊断出异常后，在执行阶段**除采纳方案外**，按规则表自动推送规定任务、优惠券、定向消息到 wlwq。

## 2. 已实现内容

### 2.1 规则配置

- **`src/core/indicator_push_rules.py`**  
  - `INDICATOR_PUSH_RULES`: 指标 code → `tasks` / `coupon_campaign` / `message`。  
  - 覆盖：线索转化率、优惠券核销率、复购率、退款率、好评率、发货时效、流失率。

### 2.2 执行节点

- **`src/agent/nodes/execute.py`**  
  - 在已有「采纳方案 → 任务/优惠券」之上，增加：  
    - 根据 `state.anomalies` 中每个 `indicator_code` 查 `INDICATOR_PUSH_RULES`；  
    - 汇总规则中的 **tasks**，去重后一次调用 `create_execution_tasks(plan_id="rule_5.2.3", tasks=...)`；  
    - 对规则中的 **coupon_campaign** 按指标去重后调用 `create_coupon_campaign`（缺省 7 天有效期）；  
    - 对规则中的 **message** 按 (指标, type) 去重后调用 `send_customer_targeted_message`。  
  - 部门负责人解析：`_dept_resolve` / `_build_tasks_from_rule_specs`，与现有方案任务共用 `get_dept_structure`。

### 2.3 通知能力

- **`src/mcp_servers/notify_server.py`**  
  - 新增工具：`send_customer_targeted_message(tenant_id, store_id, target_segment, title, content, message_type)`。  
  - 内部请求 wlwq：`POST /message-remind/targeted`。

- **`src/mcp_servers/biz_api_client.py`**  
  - 为 `/message-remind/targeted` 增加 mock 返回值。

### 2.4 wlwq 接口占位

- **`src/wlwq/routes/exec_task.py`**（新）  
  - `POST /ai-diagnosis/exec-task/batch-create`：接收 `storeId, planId, tasks[]`，返回 `{ tasks, count }`，TODO 落库。  
  - `PUT /ai-diagnosis/exec-task/{task_id}/status`：更新任务状态占位。

- **`src/wlwq/routes/message.py`**  
  - `POST /message-remind/targeted`：接收 `storeId, targetSegment, title, content, type`，返回 `{ sent_count }`，TODO 按人群推送。

- **`src/wlwq/app.py`**  
  - 注册 `exec_task.router`。

### 2.5 方案生成

- **`src/agent/prompts/solution_generation.py`**  
  - 在 system prompt 中说明：系统会按 5.2.3 自动补全规定动作，LLM 可在此基础上补充或细化步骤。

## 3. 与表格 5.2.3 的对应关系

| 异常指标           | 规则动作 | 实现方式 |
|--------------------|----------|----------|
| 线索转化率低       | 执行任务 | `lead_conversion_rate` → tasks: 线索跟进优化 → 销售，24h 内 |
| 优惠券核销率低     | 任务+消息 | tasks: 优惠券策略调整；message: target_segment=coupon_expiring_soon |
| 复购率低           | 优惠券活动 | coupon_campaign: 老客户回馈，target_customers=no_repurchase_90d |
| 退款率高           | 执行任务 | tasks: 退款原因分析与商品质量改进 → 运营 |
| 好评率低           | 执行任务 | tasks: 售后服务优化 + 差评客户回访 |
| 发货时效差         | 执行任务 | tasks: 仓储发货流程优化 → 仓储 |
| 流失率高           | 优惠券+消息 | coupon_campaign: 挽回优惠券；message: churn_risk 关怀 |

## 4. 后续可完善项

1. **wlwq 落库**  
   - `POST /ai-diagnosis/exec-task/batch-create`：将 `tasks` 写入业务表（如 `ai_diagnosis_task`），并返回真实 `task_id`。  
   - `PUT /ai-diagnosis/exec-task/{task_id}/status`：更新同表状态。

2. **定向消息真实推送**  
   - `POST /message-remind/targeted`：根据 `targetSegment` 查客户/用户列表（如调 `/client-record/list?filterType=...`），再写 `message_remind` 或调推送通道。

3. **优惠券定向**  
   - wlwq 侧 `POST /coupon/create`、`/coupon/distribute` 支持 `target_customers=no_repurchase_90d` / `churn_risk` 等语义（按业务表筛选并发券）。

4. **规则可配置化**  
   - 将 `INDICATOR_PUSH_RULES` 迁至配置或 DB，便于运营按租户/行业微调。
