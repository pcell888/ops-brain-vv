# wlwq 钻取接口对比表（协议 vs 日志）

判定口径：**只看必需结构/字段**，**忽略额外字段**。钻取模式（`detail=true` 或文档指定 `filterType=...`）的 `data` 必需为 `{"total": int, "list": [...]}`。

---

## 1) 钻取扩展端点（9 个）

| 指标 | 钻取请求 | 协议要求（data 仅必需） | 日志实际（data 摘要） | 结论 | 问题点 |
|---|---|---|---|---|---|
| `coupon_redemption_rate` | `GET /account-coupon/statistics?filterType=unused&page&pageSize` | `total` + `list[]`；`list` 必需：`account_coupon_id,coupon_name,phone,use_status,start_time,end_time,create_time` | 例：`{issuedCount,totalUsed}`（无 `total/list`） | 不合规 | 明细模式未返回分页 `total/list` |
| `browse_to_order_rate` | `GET /manage-data/exposure-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`account_id,browse_time,order_count,first_order_time` | 例：`{browseUsers}` | 不合规 | 明细模式未返回分页 `total/list` |
| `order_conversion_rate` | `GET /store-order/conversion-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`account_id,order_sn,pay_time,pay_price,order_status` | 例：`{orderUsers,totalOrders,completedOrders,newCustomers}` | 不合规 | 明细模式未返回分页 `total/list` |
| `seckill_conversion_rate` | `GET /seckill-apply/conversion-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`seckill_apply_id,goods_name,goods_num,surplus_goods_num,start_time,end_time` | 例：`{totalSeckillGoods,soldGoods}` | 不合规 | 明细模式未返回分页 `total/list` |
| `refund_rate` | `GET /store-refund-order/statistics?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`store_refund_order_id,store_order_id,order_sn,refund_price,refund_cause,refund_apply_time,refund_success_time` | 例：`{totalCompletedOrders,refundOrders,...}` | 不合规 | 明细模式未返回分页 `total/list` |
| `positive_review_rate` | `GET /store-order-evaluate/statistics?filterType=negative&page&pageSize` | `total` + `list[]`；`list` 必需：`store_order_evaluate_id,store_order_id,star,level,content,create_time` | 例：`{totalReviews,positiveReviews,...}` | 不合规 | 明细模式未返回分页 `total/list` |
| `avg_customer_lifetime_value` | `GET /store-order/repurchase-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`account_id,order_count,total_amount,last_order_time` | 例：`{totalBuyers,repeatBuyers,...}` | 不合规 | 明细模式未返回分页 `total/list` |
| `service_completion_rate` | `GET /service-order/completion-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`service_order_id,order_sn,order_status,create_time,finish_time` | 例：`{totalOrders/totalServiceOrders,completedOrders,...}` | 不合规 | 明细模式未返回分页 `total/list` |
| `avg_shipping_hours` | `GET /store-order/shipping-stats?detail=true&page&pageSize` | `total` + `list[]`；`list` 必需：`store_order_id,order_sn,pay_time,delivery_time,shipping_hours` | 例：`{avgShippingHours}` | 不合规 | 明细模式未返回分页 `total/list` |
