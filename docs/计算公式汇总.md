# 企业运营AI智能诊断系统 - 计算公式说明

本文档面向产品同事，用通俗的语言解释系统中各项指标和评分的计算方式。

---

## 一、指标说明

系统会从业务系统获取数据，计算出以下14项运营指标：

| 指标名称 | 说明 | 越高越好 | 单位 |
|---------|------|:-------:|------|
| 线索转化率 | 签约客户数 / 线索总数 | ✅ | % |
| 平均响应时间 | 业务响应客户所需的平均小时数 | ❌ | 小时 |
| 跟进次数 | 业务人员跟进客户的总次数 | ✅ | 次 |
| 优惠券核销率 | 已使用优惠券 / 已发放优惠券 | ✅ | % |
| 浏览-下单转化率 | 下单用户数 / 浏览用户数 | ✅ | % |
| 订单转化率 | 已完成订单 / 总订单 | ✅ | % |
| 秒杀转化率 | 已售秒杀商品 / 秒杀商品总数 | ✅ | % |
| 复购率 | 复购客户数 / 总客户数 | ✅ | % |
| 退款率 | 退款订单 / 已完成订单 | ❌ | % |
| 流失率 | 流失客户 / 活跃客户 | ❌ | % |
| 好评率 | 好评数 / 总评价数 | ✅ | % |
| 平均客户生命周期价值 | 客户在整个消费周期内的平均消费金额 | ✅ | 元 |
| 服务完成率 | 已完成服务单 / 服务单总数 | ✅ | % |
| 平均发货时长 | 从下单到发货的平均小时数 | ❌ | 小时 |

> 注：✅ 表示该指标越高越好，❌ 表示该指标越低越好

---

## 二、综合健康度评分

系统会对企业进行综合健康度评分（满分100分），分四个维度进行评估：

### 维度与权重

| 维度 | 占比 | 包含指标 |
|------|:----:|---------|
| 营销 | 30% | 优惠券核销率、浏览-下单转化率、订单转化率、秒杀转化率 |
| 客户留存 | 30% | 复购率、退款率、流失率、好评率、平均客户生命周期价值 |
| CRM | 25% | 线索转化率、平均响应时间、跟进次数 |
| 运营效率 | 15% | 服务完成率、平均发货时长 |

### 评分流程

**第一步：计算偏离度**

将企业指标值与行业均值对比，计算偏离程度：

- **越高越好的指标**：偏离度 = (企业值 - 行业均值) / 行业均值 × 100%
- **越低越好的指标**：偏离度 = (行业均值 - 企业值) / 行业均值 × 100%

**第二步：计算单指标得分**

根据偏离度计算每项指标的得分：

```
指标得分 = 60 + 偏离度 × 0.4
```

得分范围限制在 0-100 分。

> 举例：假设行业线索转化率均值为5%，某企业为4%，偏离度 = (4-5)/5 × 100% = -20%
> 该企业该项指标得分 = 60 + (-20) × 0.4 = 52分

**第三步：计算维度得分**

将同一维度下所有指标得分取平均值，即为该维度得分。

**第四步：计算综合健康度**

```
综合健康度 = 营销维度得分 × 30% + 客户留存维度得分 × 30% + CRM维度得分 × 25% + 运营效率维度得分 × 15%
```

---

## 三、异常指标判定

当某项指标的偏离度低于 -15% 时，系统判定该指标为**异常指标**。

### 异常严重程度

| 严重程度 | 偏离度条件 |
|---------|-----------|
| 🔴 高风险 | 偏离度 < -30% |
| 🟡 中风险 | -30% ≤ 偏离度 < -20% |
| 🟢 低风险 | -20% ≤ 偏离度 < -15% |

---

## 四、效果追踪

### 指标变化率

方案执行后，系统会自动对比前后指标变化：

```
变化率 = (执行后值 - 执行前值) / |执行前值| × 100%
```

- 如果指标是"越高越好"，变化率为正表示改善
- 如果指标是"越低越好"，变化率为负表示改善

### 目标达成率

达成率的计算方式：

```
达成率 = 有所改善的指标数 / 跟踪的指标总数 × 100%
```

当达成率 ≥ 50% 时，系统会将该方案经验写入知识库，供后续参考。

## 六、方案 ROI 与优先级

系统生成优化方案时，会为每个方案计算优先级得分，并据此排序和推荐。

### 预期 ROI（expected_roi）

预期 ROI 由 AI 模型根据企业画像、异常指标、根因分析、行业基准、历史案例等上下文信息综合评估后给出，取值范围为 1-10 分。

> 理论公式：预期ROI = 预期收益 / 实施成本
>
> 实际实现中由 AI 直接估算输出 1-10 的分值，而非通过公式显式计算。原因如下：
> - **预期收益无法精确量化**：优化方案的收益涉及品牌影响、客户满意度提升、长期复购增长等难以直接货币化的因素，且受市场环境、竞争态势等不确定因素影响
> - **实施成本无法精确量化**：方案执行涉及人力投入、时间成本、资源调配等，业务系统中缺乏这些成本数据，且不同企业的成本结构差异较大
> - **选择 1-10 量表**：与实施难度（1-10）和紧急程度（1-10）量纲统一，确保优先级得分公式中三个维度在同一尺度上可加权求和，最终优先级得分也在 0-10 范围内

### 实施难度（difficulty_score）

由 AI 模型评估方案的实施难度，取值范围为 1-10 分（1 = 最容易，10 = 最困难），默认值为 5。

### 紧急程度（urgency_score）

由 AI 模型评估方案的紧急程度，取值范围为 1-10 分（1 = 最不紧急，10 = 最紧急），默认值为 5。

### 优先级得分（priority_score）

```
优先级得分 = 预期ROI × 60% + (10 - 实施难度) × 20% + 紧急程度 × 20%
```

| 维度 | 权重 | 说明 |
|------|:----:|------|
| 预期ROI | 60% | ROI 越高，优先级越高 |
| 实施难度 | 20% | 难度越低，优先级越高（反向计分，用 10 减去难度值） |
| 紧急程度 | 20% | 越紧急，优先级越高 |

> 举例：某方案预期ROI为7，实施难度为4，紧急程度为8
> 优先级得分 = 7 × 0.6 + (10 - 4) × 0.2 + 8 × 0.2 = 4.2 + 1.2 + 1.6 = 7.0

### 方案排序

所有方案按优先级得分**从高到低**排列，得分最高的方案排在最前面。

### 推荐方案

系统自动选择优先级得分最高的方案作为推荐方案，并给出推荐理由：

- 若该方案的预期 ROI 在所有方案中最高 → "ROI 最高"
- 若该方案的实施难度在所有方案中最低 → "执行难度最低"
- 若该方案的紧急程度在所有方案中最高 → "紧急度最高"
- 若以上均不满足 → "综合优先级得分最高"

## 七、评分等级参考

| 健康度评分 | 等级 | 说明 |
|:---------:|:----:|------|
| 80-100 | 优秀 | 各项指标表现优异 |
| 60-79 | 良好 | 整体运营正常，有少量指标可优化 |
| 40-59 | 一般 | 部分指标存在问题，需要关注 |
| 0-39 | 异常 | 多项指标异常，需要重点改进 |
