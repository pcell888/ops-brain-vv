# 企业运营AI智能诊断系统 - 计算公式说明

本文档面向产品同事，用通俗的语言解释系统中各项指标和评分的计算方式。

---

## 一、指标说明

系统会从业务系统获取数据，计算出以下14项运营指标：

| 指标名称 | 说明 | 越高越好 | 单位 |
|---------|------|:-------:|------|
| 线索转化率 | 签约客户数 / 线索总数 | ✅ | % |
| 平均响应时间 | 业务响应客户所需的平均小时数 | ❌ | 小时 |
| 跟进次数 | 业务人员跟进客户的总次数 | ✅ | 次 |
| 优惠券核销率 | 已使用优惠券 / 已发放优惠券 | ✅ | % |
| 浏览-下单转化率 | 下单用户数 / 浏览用户数 | ✅ | % |
| 订单转化率 | 已完成订单 / 总订单 | ✅ | % |
| 秒杀转化率 | 已售秒杀商品 / 秒杀商品总数 | ✅ | % |
| 复购率 | 复购客户数 / 总客户数 | ✅ | % |
| 退款率 | 退款订单 / 已完成订单 | ❌ | % |
| 流失率 | 流失客户 / 活跃客户 | ❌ | % |
| 好评率 | 好评数 / 总评价数 | ✅ | % |
| 平均客户生命周期价值 | 客户在整个消费周期内的平均消费金额 | ✅ | 元 |
| 服务完成率 | 已完成服务单 / 服务单总数 | ✅ | % |
| 平均发货时长 | 从下单到发货的平均小时数 | ❌ | 小时 |

> 注：✅ 表示该指标越高越好，❌ 表示该指标越低越好

---

## 二、综合健康度评分

系统会对企业进行综合健康度评分（满分100分），分四个维度进行评估：

### 维度与权重

| 维度 | 占比 | 包含指标 |
|------|:----:|---------|
| 营销 | 30% | 优惠券核销率、浏览-下单转化率、订单转化率、秒杀转化率 |
| 客户留存 | 30% | 复购率、退款率、流失率、好评率、平均客户生命周期价值 |
| CRM | 25% | 线索转化率、平均响应时间、跟进次数 |
| 运营效率 | 15% | 服务完成率、平均发货时长 |

### 评分流程

**第一步：计算偏离度**

将企业指标值与行业均值对比，计算偏离程度：

- **越高越好的指标**：偏离度 = (企业值 - 行业均值) / 行业均值 × 100%
- **越低越好的指标**：偏离度 = (行业均值 - 企业值) / 行业均值 × 100%

**第二步：计算单指标得分**

根据偏离度计算每项指标的得分：

```
指标得分 = 60 + 偏离度 × 0.4
```

得分范围限制在 0-100 分。

> 举例：假设行业线索转化率均值为5%，某企业为4%，偏离度 = (4-5)/5 × 100% = -20%
> 该企业该项指标得分 = 60 + (-20) × 0.4 = 52分

**第三步：计算维度得分**

将同一维度下所有指标得分取平均值，即为该维度得分。

**第四步：计算综合健康度**

```
综合健康度 = 营销维度得分 × 30% + 客户留存维度得分 × 30% + CRM维度得分 × 25% + 运营效率维度得分 × 15%
```

---

## 三、异常指标判定

当某项指标的偏离度低于 -15% 时，系统判定该指标为**异常指标**。

### 异常严重程度

| 严重程度 | 偏离度条件 |
|---------|-----------|
| 🔴 高风险 | 偏离度 < -30% |
| 🟡 中风险 | -30% ≤ 偏离度 < -20% |
| 🟢 低风险 | -20% ≤ 偏离度 < -15% |

---

## 四、效果追踪

### 指标变化率

方案执行后，系统会自动对比前后指标变化：

```
变化率 = (执行后值 - 执行前值) / |执行前值| × 100%
```

- 如果指标是"越高越好"，变化率为正表示改善
- 如果指标是"越低越好"，变化率为负表示改善

### 目标达成率

达成率的计算方式：

```
达成率 = 有所改善的指标数 / 跟踪的指标总数 × 100%
```

当达成率 ≥ 50% 时，系统会将该方案经验写入知识库，供后续参考。

## 六、评分等级参考

| 健康度评分 | 等级 | 说明 |
|:---------:|:----:|------|
| 80-100 | 优秀 | 各项指标表现优异 |
| 60-79 | 良好 | 整体运营正常，有少量指标可优化 |
| 40-59 | 一般 | 部分指标存在问题，需要关注 |
| 0-39 | 异常 | 多项指标异常，需要重点改进 |
